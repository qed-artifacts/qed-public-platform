# QED-AI public platform instructions

This public repository is the shared rendering and deployment control plane for
QED-AI domain portals. Changes can affect multiple public sites. Preserve schema
compatibility, validate every example, and document migrations before removing
or renaming fields.

Never add credentials, private source material, internal SharePoint URLs,
signatures, recordings, residential addresses, confidential records, or personal
data. Keep the renderer dependency-free unless a dependency has a compelling,
documented benefit and an appropriate security review.
