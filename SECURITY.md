# Security policy

Report suspected security or privacy issues privately to
[contact@qedartifacts.org](mailto:contact@qedartifacts.org). Do not include
sensitive details in a public issue, pull request, discussion, commit, or build
log.

This renderer processes public repository content only. It must not fetch from
restricted SharePoint locations, embed credentials, or publish private source
paths. Generated releases should be treated as unrestricted public information.
